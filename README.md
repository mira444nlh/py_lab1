# toolkit
Python-пакет с CLI, содержащий калькулятор арифметических выражений и конвертер величин (длина, масса, температура).

## Возможности

- `calc` — вычисление арифметических выражений: `+ - * / % // **`, скобки, унарный плюс и минус.
- `convert` — конвертация величин между единицами одной категории:
  - длина: `mm`, `cm`, `m`, `km`
  - масса: `g`, `kg`
  - температура: `c` (Цельсий), `f` (Фаренгейт), `k` (Кельвин)
- Ошибки выводятся в `stderr` с кодом завершения `2`, а результат в `stdout` с кодом `0`.

## Использование

Команды запускаются через `python -m toolkit`.

### calc

```bash
python -m toolkit calc "2+2*2"
# 6

python -m toolkit calc "(2+3)*4"
# 20
```

Выражение с ведущим минусом или начинающееся с `-`/`--` нужно передавать после `--`, чтобы argparse не принял его за флаг:

```bash
python -m toolkit calc -- "-5+3"
# -2
```

### convert

```bash
python -m toolkit convert 1000 --from m --to km
# 1.0

python -m toolkit convert 0 --from c --to f
# 32.0
```

### Справка

```bash
python -m toolkit --help
python -m toolkit calc --help
python -m toolkit convert --help
```

## Описание модулей

### `__main__.py`

Точка входа CLI. Строит парсер аргументов (`argparse`) с двумя подкомандами, `calc` и `convert`, и вызывает соответствующий обработчик.

- `calc_cmd(args)` — вызывает `evaluate()` из `calculator.py` и печатает результат. Если выражение некорректно или в нём деление на ноль, ловит `ValueError`/`ZeroDivisionError`, печатает сообщение в `stderr` и завершает программу с кодом `2`.
- `convert_cmd(args)` — сначала пытается превратить `value` в `float` (если не получилось — ошибка в `stderr`, код `2`), затем вызывает `convert()` из `converter.py`. Единицы измерения (`--from`, `--to`) приводятся к нижнему регистру перед вызовом.
- `main()` — собирает парсер и его подкоманды, разбирает аргументы командной строки и запускает функцию, привязанную к выбранной подкоманде (`args.func(args)`).

 ### `calculator.py`

Вычислительное ядро калькулятора. Обрабатывает выражение в три этапа: токенизация → валидация → вычисление.

- `tokenize(expr)` — разбивает строку выражения на токены: числа (`NUMBER`) и операторы/скобки (`OPERATOR`). Пробелы пропускает, на неизвестном символе кидает `ValueError`.
- `validation(tokens)` — проверяет корректность последовательности токенов: баланс скобок, отсутствие двух операторов подряд, отсутствие пропущенных операндов. Заодно сворачивает подряд идущие `/` и `*` в `//` и `**`, а унарные плюс и минус в знак числа.
- `calculate(tokens)` — основной цикл вычисления по алгоритму сортировочной станции (shunting-yard): числа сразу кладутся в стек, операторы применяются с учётом приоритета и скобок.
- `evaluate(expression)` — публичная функция модуля: последовательно вызывает `tokenize()`, `validation()` и `calculate()`, возвращает итоговое число.

### `converter.py`

Вычислительное ядро конвертера единиц измерения.

- `convert(value, unit_from, unit_to)` — основная функция:
  1. проверяет, что обе единицы известны и относятся к одной категории (длина, масса или температура), иначе кидает `ValueError`;
  2. для длины и массы делает прямой пересчёт через таблицу коэффициентов (`length_mass_convert`);
  3. для температуры переводит значение через градусы Цельсия как промежуточный шаг и проверяет, что результат не ниже абсолютного нуля (`ABSOLUTE_ZERO_CELCIUS` из `constants.py`).

### `constants.py`

Содержит общие константы проекта — в частности, `ABSOLUTE_ZERO_CELCIUS` (значение абсолютного нуля в градусах Цельсия), которое используют `convert()`, `unit_to_celcius()` и `celcius_to_unit()`.

### `errors.py`

Содержит описание пользовательских исключений. Образует единую иерархию, унаследованную от `ToolkitError`.

## Тесты

Тесты лежат в `src/tests/` и разделены по модулям:

- `test_calculator.py` — вычислительное ядро (`toolkit.calculator.evaluate`).
- `test_converter.py` — вычислительное ядро (`toolkit.converter.convert`).
- `test_cli.py` — интерфейс командной строки через `subprocess`, с проверкой `stdout`, `stderr` и кода завершения.


## Обработка ошибок

| Ситуация                                     | Код выхода | Куда выводится |
| -------------------------------------------- | :--------: | -------------- |
| Успешный результат                           |     0      | stdout         |
| `--help`                                     |     0      | stdout         |
| Некорректное выражение (`calc`)              |     2      | stderr         |
| Деление на ноль                              |     2      | stderr         |
| Неизвестная или несовместимая единица        |     2      | stderr         |
| Неверное числовое значение (`convert`)       |     2      | stderr         |
| Температура ниже абсолютного нуля            |     2      | stderr         |
| Отсутствует обязательный аргумент (argparse) |     2      | stderr         |

К некорректным выражениям (`calc`) относятся синтаксические ошибки следующих типов:
- Пустое выражение;
- Недопустимый символ;
- Пропущенный операнд/оператор;
- Два бинарных оператора подряд;
- Неправильный формат скобок.
